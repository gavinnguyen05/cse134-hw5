## Random Fact Component

I added a random fact generator to the Web Component section of `experiments.html`, the component is defined in `fact-panel.js` and gets its facts from the Useless Facts API.

### Design Note

Visitors browse random facts without having to refresh or leave the page. A fact is loaded when the page first opens, and clicking Next fact uses `fetch()` to get another one from the API. While waiting, the button is temporarily disabled and a loading message is shown. If the request works and the returned text is valid, the fact is updated using `textContent`. If something goes wrong, the previous fact stays on the page and an error message appears. The button is enabled again so the visitor can try again. I also used `role="status"` so screen readers can announce these updates.

### Compact Mode Preference

I added a button outside the component that toggles the `compact` attribute to switch between compact and expanded view. Compact view hides the description without changing the current fact. The selected view is saved in `localStorage` using the key `hw5-fact-panel-mode` so it stays the same after refreshing. If there is no valid saved preference, the component defaults to expanded view. The toggle still works even if localStorage is unavailable.

I used CSS variables (`--panel-background`, `--panel-text`, and `--panel-border`) to match the existing light and dark themes of my portfolio. If JavaScript is disabled, the toggle button stays hidden and a message asks the visitor to enable JavaScript.
